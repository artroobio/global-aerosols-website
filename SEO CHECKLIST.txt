<!--
  LCP (Largest Contentful Paint) – Target: < 2.5 s
    - Preload the hero/H1 image using <link rel="preload" as="image">
    - Serve images in WebP or AVIF format
    - Use a CDN for static assets
    - Avoid render-blocking CSS/JS above the fold

  FID / INP (Interaction to Next Paint) – Target: < 200 ms
    - Defer or async non-critical JavaScript
    - Break up long JavaScript tasks (> 50 ms)
    - Avoid third-party scripts loading synchronously

  CLS (Cumulative Layout Shift) – Target: < 0.1
    - Always set explicit width and height on <img> and <video> elements
    - Reserve space for ads, embeds, and dynamically injected content
    - Do not insert content above existing content on load
-->
